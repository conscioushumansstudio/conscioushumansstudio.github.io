# conscioushumansstudio.com

Public website for Conscious Humans Studio, served by GitHub Pages with the custom domain in `CNAME`.

- `/` studio home
- `/streakrewards/` app page, plus `privacy/`, `terms/`, `support/`, `delete-account/` (store-required links)
- `/streakrewards/#privacy` (and the other names) redirect to the matching page

Only static HTML and CSS live here. No app code, keys or config.
